# Landing Page Heros Food Mcz

Primeira versão funcional desenvolvida em HTML5, CSS3 e JavaScript vanilla para o projeto Impulso Web do CESMAC.

## Como abrir

1. Extraia a pasta do projeto.
2. Abra `index.html` diretamente no navegador.
3. Para editar com atualização automática, abra a pasta no VS Code e utilize a extensão Live Server.

Não é necessário instalar dependências, executar comandos ou iniciar servidor.

## Arquivos principais

- `index.html`: estrutura e conteúdo da página.
- `assets/css/style.css`: identidade visual e responsividade.
- `assets/js/script.js`: menu mobile, filtros, carrossel, links do WhatsApp e ano do rodapé.
- `assets/images/`: materiais enviados e recortes provisórios do protótipo.

- Substituir os recortes do protótipo por fotografias originais em alta resolução.

- Inserir links oficiais do iFood, 99Food, Rappi e Google Maps.

## Observação

Todos os preços foram omitidos conforme decisão do cliente. A página não processa pedidos ou pagamentos; os contatos são direcionados ao WhatsApp.
